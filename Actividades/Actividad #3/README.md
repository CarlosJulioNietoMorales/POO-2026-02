## Descripción

Solución de los ejercicios **8.2** y **8.3** del libro *Ejercicios de programación orientada a objetos con Java y UML* (Leonardo Bermón Angarita), desarrollados en Java con interfaz gráfica Swing, incluyendo la parte propuesta de cada ejercicio.

### Ejercicio 8.2 - Notas
Ventana que recibe cinco notas y calcula el promedio, la desviación estándar, la mayor nota y la menor nota.
- Parte propuesta: alerta cuando se ingresa un dato no numérico y alerta cuando falta una nota (las cinco son obligatorias).
- Código: `ejercicio_8_2_notas/src/notas`

### Ejercicio 8.3 - Figuras
Ventana principal con un botón por figura geométrica. Cada botón abre una ventana donde se ingresan las dimensiones y se calcula el volumen y la superficie.
- Figuras: cilindro, esfera y pirámide.
- Parte propuesta: se agregaron el cubo y el prisma rectangular, y cada figura muestra su imagen.
- Código: `ejercicio_8_3_figuras/src/figuras`
